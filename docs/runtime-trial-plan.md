# Runtime Trial Plan

Use this only after pattern-only review is complete.

## Phase 1: file-only dry run

- validate example packets
- create a fake task packet
- create a fake result packet
- review a fake memory delta

## Phase 2: GenericAgent disposable browser trial

- use a disposable browser profile
- use fake/local pages only
- deny cookie access
- allow screenshots only under ignored handoff paths
- write result and evidence packets manually or through a local adapter

## Phase 3: OpenHuman memory review trial

- import only a reviewed fake memory delta
- verify the memory is visible and editable
- verify rollback path

## Phase 4: real connector or account trial

- only after disposable trials pass
- name account lock owner
- name profile and connector scope
- record cleanup and revocation steps
